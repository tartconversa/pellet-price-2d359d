# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

offer 是报价机会，不是实际可购买到货。eligible=false 为客观不能响应，accepted=false 为未成交。检查以 truck_id 区分车次，final_sample 指裁定使用的留样记录；assays 同车多行不得扩增车次。water_pct/ash_pct 是质量百分数，calorific_mj_t 是每干吨兆焦，误差组相同的分量不能独立抽签。报价和成本是输入事实，不包含行为弹性答案。合同奖扣为每湿吨金额；按段左闭右开，最后一段无上限。保底及复检承担作为合同责任，不因参与预测而消失。
heat_deduction_rate 按干基热值低于 reference_heat 的差每100兆焦每湿吨扣款，高于基准不自动加奖；含水奖扣按对应段叠加。最低供方收益按其获分配量扣原料、实际或反事实干燥成本和运费，以及合同指定复检成本；参与变化须有证据，反事实成本不能直接沿用已选优来料均值。合同 guaranteed_t 是采购总承诺，不能随预测退出而消除。rulings 新裁定的样本在其可知时点替换原 final_sample，旧报价和旧裁定依据保留。
灰分超过 ash_limit_pct 的差按百分点乘 ash_penalty_yuan_pct 扣每湿吨价，与含水奖扣及热值扣款同时生效；低灰分奖励体现为免扣，不存在未登记的额外奖励。
final_sample 为空表示本车无实验室裁定，不能从报价或供应商均值造一条实测值；复检选择也不是随机抽样。

## suppliers
供方能力与客观机会。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| supplier_id | string | 供方 |
| capacity_t | number | 周期湿吨能力 |
| distance_km | number | 运距 |
| dry_cost_yuan | number | 每降低一含水百分点每吨成本 |
| transport_yuan_t | number | 每湿吨运费 |
| raw_cost_yuan_t | number | 原料购入元每湿吨 |

记录键：supplier_id。

## offers
包括未成交的真实询价机会。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| offer_id | string | 报价 |
| period | integer | 周期 |
| supplier_id | string | 供方 |
| quoted_price | number | 每湿吨报价 |
| offered_t | number | 可供湿吨 |
| eligible | boolean | 可响应 |
| accepted | boolean | 成交 |
| reason | string | 结果原因 |
| available_at | datetime | 可知时刻 |

记录键：offer_id。

## trucks
实际接收与最终裁定引用，drying_cost 是本车加工成本。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| truck_id | string | 车次 |
| offer_id | string | 报价 |
| wet_t | number | 湿吨 |
| drying_cost | number | 加工元每湿吨 |
| final_sample | string | 裁定留样 |
| available_at | datetime | 可知时刻 |

记录键：truck_id。

## assays
含按质量边界选择的复检。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| sample_id | string | 留样 |
| truck_id | string | 车次 |
| round | integer | 检验次序 |
| water_pct | number | 含水率 |
| ash_pct | number | 灰分 |
| calorific_mj_t | number | 干基热值 |
| water_error | number | 水分误差尺度 |
| ash_error | number | 灰分误差尺度 |
| heat_error | number | 热值误差尺度 |
| error_group | string | 共同误差组 |
| selection_reason | string | 抽检原因 |
| available_at | datetime | 可知时刻 |

记录键：sample_id。

## lab_error
共同测量误差的相关结构，变量顺序见 left/right。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| pair_id | string | 配对 |
| left | string | 变量 |
| right | string | 变量 |
| correlation | number | 相关 |

记录键：pair_id。

## contract_terms
候选合同，最低收益指供方周期净收益下限，热量可靠性由 demand 规定。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| contract_id | string | 合同 |
| base_price | number | 每湿吨基价 |
| reference_heat | number | 基准干基热值 |
| guaranteed_t | number | 总保底湿吨 |
| recheck_payer | string | buyer或supplier |
| recheck_yuan | number | 每次复检费用 |
| min_supplier_net | number | 供方最低净收益 |
| ash_limit_pct | number | 灰分罚扣起点百分比 |
| ash_penalty_yuan_pct | number | 每超一灰分百分点每湿吨扣款 |

记录键：contract_id。

## adjustments
按含水率分段奖扣，可与热值差额同时生效。rate 为每低于基准100兆焦每湿吨扣款。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| row_id | string | 分段 |
| contract_id | string | 合同 |
| water_from | number | 含水率下界 |
| water_to | number | 上界空为无穷 |
| bonus_yuan_t | number | 每湿吨奖扣 |
| heat_deduction_rate | number | 热值差额扣款 |

记录键：row_id。

## demand
同一采购周期的热量保证与允许风险。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| requirement_id | string | 要求 |
| heat_mj | number | 需求兆焦 |
| shortfall_risk_max | number | 最大缺供概率 |

记录键：requirement_id。

## rulings
签约后进入的争议裁定，替换留样而非增加车次。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| ruling_id | string | 裁定 |
| truck_id | string | 车次 |
| replacement_sample | string | 新裁定样 |
| available_at | datetime | 可知时刻 |

记录键：ruling_id。
